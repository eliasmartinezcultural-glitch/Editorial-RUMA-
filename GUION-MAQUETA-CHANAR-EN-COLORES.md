## Reglas de adaptación del guion

1. Si no hay evidencia suficiente para una página histórica, no se rellena: se cambia por una página de observación o se reordena el índice.
2. Los testimonios no reemplazan documentos para probar fechas; aportan memoria y experiencia.
3. La presencia mapuche y criolla no puede reducirse a un recuadro decorativo. Requiere investigación específica, lenguaje cuidadoso y, cuando sea posible, consulta de voces pertinentes.
4. El mapa debe distinguir claramente la ubicación actual de los lugares históricos hipotéticos.
5. Las escenas ilustradas de época deben basarse en fotografías, planos, descripciones o referencias verificables. Si son recreaciones interpretativas, se rotulan como tales.
6. Las actividades deben reforzar lo aprendido, no funcionar como relleno.

## Plantilla de una página de contenido

- **Título:** una frase concreta y atractiva.
- **Idea central:** una sola cosa que el lector debe comprender.
- **Texto principal:** 60–110 palabras como objetivo inicial, según página.
- **Elemento visual dominante:** ilustración, mapa, diagrama o fotografía.
- **Microdato:** solo si tiene fuente.
- **Actividad:** opcional, breve y relacionada.
- **Referencia interna:** ID de fuente en el archivo maestro.
