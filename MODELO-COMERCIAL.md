# Modelo comercial de Editorial RUMA

## Qué ofrece RUMA
Un catálogo curado de publicaciones digitales terminadas. El valor está en el contenido, la utilidad, el diseño y la facilidad de acceso; no en prometer una plataforma tecnológica compleja.

## Roles
- **Ocarina Producciones:** investiga, desarrolla, produce y revisa las obras originales.
- **Editorial RUMA:** organiza el catálogo, presenta las publicaciones, informa condiciones y conecta con el mecanismo de compra.
- **Cada publicación:** tiene identidad, contenido, precio, muestra y condiciones propias.

## Modelo inicial recomendado
1. Mostrar gratuitamente la ficha de cada obra.
2. Ofrecer una muestra real y limitada cuando sea útil.
3. Cobrar por el archivo completo mediante un proveedor externo.
4. Entregar el archivo después de que el proveedor confirme el pago.
5. Mantener un canal de contacto para consultas y problemas.

## Lo que el sitio estático no hace
GitHub Pages no procesa pagos, no valida transferencias, no administra pedidos, no protege archivos privados ni envía correos transaccionales. No se debe simular ninguna de esas funciones.

## Reglas para proteger ingresos y confianza
- Nunca subir el archivo pago completo a una carpeta pública del repositorio.
- No publicar un enlace de descarga directa antes del pago.
- No anunciar disponibilidad si no se probó la entrega.
- Informar formato, páginas, compatibilidad, precio y alcance.
- Conservar una copia maestra y una versión de entrega.
- Registrar costos, comisiones y tiempo de producción para evaluar rentabilidad.

## Criterio de precio
El precio no debe fijarse solo por cantidad de páginas. Considerar investigación, diseño, corrección, derechos, comisiones, soporte y valor práctico para quien compra. Revisar el precio cuando cambien los costos o el alcance.

## Próxima etapa técnica
Elegir un proveedor que opere en Argentina, permita cobrar y entregar archivos digitales, y revisar sus comisiones, condiciones y experiencia de compra antes de integrarlo. La elección debe hacerse con datos actuales y sin comprometer archivos pagos.
