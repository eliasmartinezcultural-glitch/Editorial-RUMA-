# Control de calidad antes de publicar

## 1. Contenido
- [ ] El material cumple un propósito claro.
- [ ] Los datos verificables tienen fuentes identificables.
- [ ] Las opiniones e interpretaciones están diferenciadas de los hechos.
- [ ] Los nombres, fechas, lugares y citas fueron revisados.
- [ ] No hay contenido copiado sin permiso o atribución.

## 2. Derechos y cuidado
- [ ] Autoría definida.
- [ ] Permisos de fotografías, ilustraciones y testimonios documentados.
- [ ] Créditos visibles dentro de la publicación.
- [ ] No se exponen datos personales sin autorización.

## 3. Diseño y archivo
- [ ] Títulos y textos legibles en pantalla pequeña.
- [ ] Contraste suficiente.
- [ ] Páginas ordenadas y numeradas cuando corresponda.
- [ ] No hay elementos cortados ni páginas vacías accidentales.
- [ ] PDF abre correctamente en más de un dispositivo.
- [ ] La impresión de prueba no corta textos ni ilustraciones.

## 4. Experiencia de compra
- [ ] La ficha describe exactamente lo que se entrega.
- [ ] El precio y la moneda son claros.
- [ ] El botón de compra lleva al proveedor correcto.
- [ ] Se realizó una compra de prueba.
- [ ] La entrega funciona y el archivo recibido abre.
- [ ] Existe un canal de contacto para problemas.

## 5. Decisión
- **APROBADA:** todos los puntos críticos están resueltos.
- **PENDIENTE:** falta corregir o probar algún punto.
- **RETIRADA:** hay un problema de derechos, exactitud o entrega.

La velocidad de publicación nunca justifica sacrificar confianza.
